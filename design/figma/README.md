# Anixart — макет текущего приложения

**24 экрана в светлой и тёмной темах**, по текущему SwiftUI-коду. Размер каждого экрана — **393 × 852**. Это реконструкция интерфейса, не редизайн и не скриншоты работающего приложения.

## Быстро открыть в Figma

1. Создайте пустой **Figma Design**-файл.
2. Перетащите **`Anixart-current-ui-light.svg`** или **`Anixart-current-ui-dark.svg`** прямо на холст.
3. Для одного экрана используйте SVG из `screens/light/` или `screens/dark/`.

SVG содержит постеры и шрифты внутри файла. Не нужно устанавливать расширение или подключать API. Весь комплект для передачи находится в **`Anixart-Figma.zip`**. Его сначала нужно распаковать; ZIP не является Figma-файлом.

> SVG импортируется **на холст**, а не через «Open» на стартовой странице Figma. При обычном SVG-импорте текст может стать векторными контурами. Для редактируемого текста используйте импортёр ниже.

## Полностью редактируемые слои

Локальный плагин создаёт новые страницы с нативными фреймами, **Text**-слоями, фигурами, векторными иконками и изображениями. Палитра и типографика становятся локальными стилями, образцы общих элементов — компонентами. Сеть, токены и вход в Anixart не нужны.

1. Откройте **настольную Figma** и пустой Design-файл.
2. В меню выберите **Plugins → Development → Import plugin from manifest…**.
3. Укажите **`figma-plugin/manifest.json`** из этого комплекта.
4. Запустите **Anixart — текущий интерфейс**, выберите тему и нажмите **«Создать макет»**.
5. Если нужен настоящий `.fig`, после импорта выберите **File → Save local copy**.

Плагин не меняет существующие страницы. При выборе обеих тем он добавляет **две** страницы; компоненты находятся ниже экранов на этих же страницах. Повторный импорт создаёт ещё одну копию, не заменяет прошлую. Если в файле уже достигнут лимит страниц, импортируйте в новый пустой файл или выбирайте одну тему.

Если Figma требует присвоить локальному плагину ID: используйте **Plugins → Development → New plugin → Figma design → Custom UI**, сохраните выданный Figma `id` в новом `manifest.json` и скопируйте туда `code.js` и `ui.html` из `figma-plugin/`. Остальные поля манифеста возьмите из комплекта. Публиковать плагин не требуется.

Для точной типографики нужен **Roboto Regular / Medium / Bold**. Figma обычно предоставляет Roboto; копии шрифтов приложения и их лицензия также лежат в `fonts/`. Если Roboto недоступен, импортёр явно предупредит и использует Inter. Раскладка основана на Roboto, поэтому с заменой возможны отличия переносов.

## Что включено

- Главная, «Моя вкладка», обзор, каталог и поиск.
- Закладки и профиль: с входом и без входа; отдельный вид статистики после прокрутки.
- Страница релиза и её описание/рейтинг, выбор озвучки и серии, комментарии.
- Расписание, уведомления, настройки, вход, фильтры.
- Окна выбора списка, оценки, настройки своей вкладки и выбора плеера.
- Отдельные панели `Anixart-components-light.svg` и `Anixart-components-dark.svg`.

Чтобы посмотреть всё **без Figma**, откройте **`preview.html`** в браузере. Там можно переключить тему и открыть отдельные экраны в полном размере.

## Точность и ограничения

- Акцент `#6B5CE8`, шрифты, размеры постеров, отступы, радиусы и подписи восстановлены из `Theme.swift`, `Typography.swift` и экранов приложения.
- Текущая сборка использует iOS 26 SDK. Системные панели, SF Symbols и статичный вид **Liquid Glass приближены**: реальное преломление и размытие зависят от iOS и фона. На iOS 17–18 системные панели и material-fallback будут отличаться.
- Здесь нет iOS-симулятора, поэтому пиксельное совпадение со сборкой **не проверено**. Точное воспроизведение потребует скриншотов с конкретного устройства и его настроек.
- Все 52 SVG проверены и отрисованы в браузере; импортёр прошёл автотесты на имитации Figma Plugin API. В настоящей Figma плагин здесь **не запускался**.
- Постеры, баннеры и общие данные релизов взяты из публичного API. Профиль `anime_fan`, друзья, закладки, уведомления и комментарии — **демонстрационные данные**, не ваш аккаунт. Реальные профили и комментарии API в комплект не сохранялись.
- Это набор основных экранов и окон, а не все возможные состояния приложения. Длинные формы показывают видимую область; веб-интерфейсы сторонних плееров, остальные экраны безопасности/тем/значков и все ошибки/загрузки не включены.
- Экранные слои имеют осмысленные названия и редактируются отдельно, но **не переведены на Auto Layout**. Компоненты даны как образцы; экранные группы не связаны с ними как instances. Прототипные переходы не настроены.
- Исходники приложения не менялись. `source-map.json` содержит пути, хеши исходников, перечень экранов и описание состояний.

## Пересобрать из репозитория

```powershell
node Tools/export-figma.mjs
node --test Tools/figma/export.test.mjs
```

Обычная пересборка использует `assets/content.json` и локальные изображения, без сети. Чтобы обновить публичные примеры и постеры:

```powershell
node Tools/export-figma.mjs --refresh-assets
```

Обычная сборка использует только Node.js 20+ и не требует npm-пакетов. При загрузке новых баннеров WebP нужен установленный **Chrome или Edge**: генератор локально переводит их в PNG, поскольку Figma API не принимает WebP. Браузер запускается без окна, с отдельным временным профилем, без доступа к вашим вкладкам и входам; изображения никуда не отправляются. Нестандартный путь к браузеру можно задать переменной `ANIXART_FIGMA_BROWSER`. В готовом комплекте уже лежат PNG, поэтому для пересборки без обновления браузер не требуется.

Изменения интерфейса в SwiftUI не преобразуются автоматически: раскладку соответствующего экрана нужно обновить в `Tools/figma/screens.mjs`, затем пересобрать экспорт.

Anixart, его контент и изображения принадлежат их правообладателям. Макет предназначен для работы над этим неофициальным клиентом. Roboto распространяется по Apache-2.0; SF Symbols как отдельные ресурсы в комплект не включены.
